#  Hangman Game - Intermediate Task

## Internship
Shadowfox Internship Program

## Description
This project is a command-line Hangman Game built using Python.
The player guesses letters to find the hidden word before losing all lives.

## Features
- Random word selection
- Input validation
- ASCII Hangman stages
- Lives system
- Win/Loss detection
