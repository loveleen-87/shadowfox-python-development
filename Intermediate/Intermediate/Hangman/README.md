##  Project Overview

Hangman is a classic word-guessing game where the player attempts to guess a hidden word one letter at a time.

The program:
- Randomly selects a word
- Tracks guessed letters
- Displays Hangman stages
- Ends when the player wins or loses all lives

### Game Rules
-The computer selects a random word.
-Player guesses one letter at a time.
-Each incorrect guess reduces one life.
-The player wins if all letters are guessed.
-The player loses if lives reach zero.
